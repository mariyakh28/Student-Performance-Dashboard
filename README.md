# Student Performance Dashboard | Power BI

## Overview
An interactive Student Performance Dashboard built using Microsoft Power BI to analyze student records, academic performance, attendance, and past failures.

## Key Metrics
- **Total Students:** 1,044
- **Students with No Past Failures:** 82%
- **Average Marks:** Analyzed using interactive KPIs
- **Highest and Lowest Marks:** Included in the dashboard

## Key Insights
- Higher student absences were associated with lower final grades.
- Students whose mothers work in the healthcare sector had an average mark of 12.7, compared with 10.5 for students whose mothers do not work.
- The dashboard provides an overview of student performance and previous failures.
